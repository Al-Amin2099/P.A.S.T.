# 🔭 P.A.S.T.
### Positional Astronomical Star Tracker

> An adaptation of Gorkem's educational, Arduino-based, mount-inspired star tracking system.
> 🔗 Original project: https://gorkem.cc/projects/StarTrack/

---

## Motivation

I got interested in astronomy and stargazing and wanted to track and photograph celestial objects from my own backyard. This project was the perfect way to combine that curiosity with hands-on building.

Along the way, I also wanted to learn more about astronomy itself, and I've documented everything on my project Notion page: https://app.notion.com/p/PROJECT-P-A-S-T-3e0fbb322cc180bc8d32e0ffdbecfc3b

---

## Project Roadmap

### Phase 1: Rebuild the Original 
Rebuild Gorkem's original design using his documented project website.

- Manufacturing - 3D Print parts
- Assembly - Assemble the mount, gears, motors, etc.
- Electrical - Wire the electronics
- Firmware - Program the Arduinos

After finishing, I found several areas I wanted to improve and ways to make the project truly my own.

### Phase 2: Refine & Upgrade 
- Electrical - Clean up the electronics
- Electrical - Design a custom PCB
- Manufacturing - Reprint higher-quality gears
- Electrical - Upgrade the motors for smoother rotation
- Firmware - Code cleanup

### Phase 3: Make It Novel 
- Build a better interface that can control the mount directly instead of entering
coordinates into a serial monitor
- Design change - ESP32 has more than enough pins, therefore I wouldn't need 2 arduinos
